## 怎么学习

首页以持续运转的三维地上地下剖面串起十三个环节：地层、封盖与多孔储层连续显示，不同井分别表现钻进、测井、完井和注采。进入视野便运转，可暂停和继续；点击环节展开对象、数据与案例。窄屏使用轻量二维剖面。没有物质流／数据流切换，也不自动巡游镜头。

每例保留专业背景、案例流程、可运行示范；已有照片、场景画卷和知识正文继续使用。录井五例打开后自动载入并分析示例，输入、处理摘要和当前结果连续显示。改变条件或导入配套观测会自动重算，操作控件与变化区域就近显示；完整公式可展开回查。

## 2026-11-03 动态全景与连续实验台

本轮仅把 **M2加权kNN** 作为重点算法可视化：同一气峰的特征 → 全部实际近邻 → 距离加权投票 → 类别票重、支持度和当前输出。点击近邻可追溯标准化差值与实际距离；切换工况时气测逐点不变，实际近邻和候选重新计算。高检测阈值不再清空参考训练库，原峰消失后调低阈值可恢复其时间锚点。其余四例突出实际方法及作用，不新增完整算法展开图。

M1保留颗粒跟踪与计数／面积；M3让基线掩膜与基线说明对应；M4明确岭回归及实际扣除项，区分最近中心与连续分段；M5保留原文编辑、字段和逐句回查，并显示陌生表达的拒判原因。配套文件仍为M1/M3像素JSON、M2气测与工况JSON、M4 CSV和M5 UTF-8 TXT。导入不接收评价真值，也不继承内置情景指标。

Live2D进站自动加载，保留原角色与同一画布；增强门户内仅显示一个助手。支持本地页面导航：例如“打开M2可运行示范”“进入钻井”“返回首页”。明确且唯一的目标直接进入，重名场景提供选择，一般知识提问不自动跳页。导航目录含65例与13阶段；在线模型配置和接口保持原样。

五份知识稿及演示中的来源说明区分真实观察、相关论文／研究报告和当前教学生成数据。M1相关论文使用CNN，当前岩屑实验采用加权kNN；M4真实USROP曲线与可控分段实验分别说明；M5相关CREWES资料是研究报告。具体关系见各例知识稿。

五例仍各5文件且低于6MiB。其他60例只同步助手与其缓存查询标识，教学计算和内容按基线核对；老师原站保护文件不变。本轮完成的数值检查、浏览器操作、下载与未验收项分别记录。原站本轮抽验M2目录导入、刷新后自动运行和工况重算；不声明五个大包能同时在原站localStorage持久保存。冷启动file://和原站沙箱下载完成仍列为未验收。

构建：`npm run build`；数值与范围核对：`npm test`；打包：`npm run package`。本轮记录位于 [dynamic-ai验收](handoff/dynamic-ai-2026-11-03/实施与验收.md)。历史1.11.0实验台及首页全景的验收保留在原日期目录。

## 录井3D与六例教学深化

录井专题只维护一份3D井场。五个对象连接岩屑、气测、荧光、钻参和报告；选择对象后可以读背景或直接进入示范。案例里的“在3D井场中定位”返回同一对象，并恢复当前会话的泵送情景、回放时刻与镜头。M1—M3是材料检测支路，M4是直接记录支路，最后汇入M5。

停泵300—480秒时，累计体积和运输进度保持平台，时钟继续推进；正常到达600秒，停泵后到达780秒。暂停播放只停止回放。计算复用原M2Core；Three.js r180随站点打包，支持离屏暂停、路由释放和二维回退。

## 离线、兼容与构建

解压离线包后双击index.html。每例独立目录仍只有case.json、README.txt、demo/index.html、demo/demo.css、demo/demo.js，单例不超过老师原站6MiB限制。老师原站支持通过“添加案例”选择完整目录；ZIP须先解压。原站背景与流程为静态预览，完整交互在可运行示范中执行。

案例正文与3D重资源按需加载。Live2D按当前要求进站自动加载；门户实验只嵌入实验区，避免重复三部分导航。三个栏目保留各自阅读位置。反馈链接打开预填页面地址的GitHub问题页面，由读者自行提交。

```sh
npm ci
npm run build
npm test
npm run serve
# 另一个终端中执行实际浏览器抽查
npm run accept
npm run package
```

本轮构建入口为tools/build-teacher-update.mjs，验证入口为checks/verify-teacher-update.mjs；本轮证据在handoff/teacher-update-2026-11-02。原1.13.0报告保留在handoff/teaching-map-2026-11-01。六例流程静态预览来自此前真实Chrome的默认计算；本轮沿用计算和预览，在示范里增加方法说明。

默认计算、图表及资料不需要在线模型。井见助手保留本地角色、紧凑对话和历史记录；教学展示默认加载加密后的连接配置，在浏览器解密并联网调用 Doubao Seed 2.0 mini，也可在“连接与语音”手动更换 Key。密文与浏览器解密材料一起随站点发布，属于展示用混淆；手动填写的 Key 仅保存在当前页面内存。更换展示 Key 可运行 `node tools/configure-assistant-demo.mjs`，在终端隐藏输入后重新同步构建。
