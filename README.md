## 怎么学习

首页以一幅三维地上地下剖面串起十三个环节，分为认识地下、钻进与取资料、建井与连通、生产与调整、储运与加工。选择设备编号或环节按钮，查看专业对象、观测数据、智能方法、输出与现有案例；可切换作业关系、物质流和数据流，播放全程或分区域观察。桌面按需加载本地三维资源，窄屏默认二维剖面并支持横向滑动。阶段编号、原场景数和案例数分别保留，也可以通过阶段、方法、难度与关键词组合查找案例。右上检索支持Ctrl/Cmd+K，命中知识小节后进入对应栏目并定位标题。

每例保留专业背景、案例流程、可运行示范。场景速览说明业务问题、实际方法、输入与用途；数据准备清单提供研究应用建议。实际演示的数据另随计算保存。背景末尾提供难度理由、参考方法链接、同场景案例与相关环节。四个拓展案例使用自己的准备条件及方法说明。

## 2026-11-03录井五例固定实验台

录井五例的流程图解沿同一个颗粒、气峰、像素、深度或原文展开，分别标明数据处理、AI核心和结果核对。讲义使用单独计算的固定示例；打开演示时只预览观测，先加载、再运行。每一步说明当前问题、处理动作与产物，完整特征和公式可以展开回查。

实验台在同一位置切换“加载数据→处理数据→交互结果”。首次成功运行后，适用条件改变自动重算；更换输入回到待处理状态，过期结果不能保存。支持下载并重新导入配套观测：M1/M3为320×240像素JSON，M2为气测与工况JSON，M4为带单位约定的CSV，M5为UTF-8原文TXT。导入观测直接参与现有模型与基线计算，不接收评价真值，也不继承内置情景的指标。

M1可从选中颗粒回查真实近邻与计数／面积贡献；M2两种输入路径使用同一份载入气测；M3用共同范围比较三方法的掩膜与像素计数；M4对照工况估计、相对响应、分组与连续段；M5原位编辑数字、否定和范围，并撤销旧修订的核对。保存接口保留原格式和原检查入口。

本轮只更新五例、对应门户内容与缓存标识。首页、助手、老师原站及其他60例的300个运行文件保持基线指纹。五例仍各5文件且低于6MiB。原站逐例目录导入和刷新重跑已验证；其localStorage容量不支持本轮实测环境下同时留存全部大包。浏览器断网后已载入页面能计算；冷启动file://及原站沙箱下载完成状态另列为未验收，不用源码检查替代。

## 录井3D与六例教学深化

录井专题只维护一份3D井场。五个对象连接岩屑、气测、荧光、钻参和报告；选择对象后可以读背景或直接进入示范。案例里的“在3D井场中定位”返回同一对象，并恢复当前会话的泵送情景、回放时刻与镜头。M1—M3是材料检测支路，M4是直接记录支路，最后汇入M5。

停泵300—480秒时，累计体积和运输进度保持平台，时钟继续推进；正常到达600秒，停泵后到达780秒。暂停播放只停止回放。计算复用原M2Core；Three.js r180随站点打包，支持离屏暂停、路由释放和二维回退。

## 离线、兼容与构建

解压离线包后双击index.html。每例独立目录仍只有case.json、README.txt、demo/index.html、demo/demo.css、demo/demo.js，单例不超过老师原站6MiB限制。老师原站支持通过“添加案例”选择完整目录；ZIP须先解压。原站背景与流程为静态预览，完整交互在可运行示范中执行。

案例正文与3D重资源按需加载。Live2D按当前要求进站自动加载；门户实验只嵌入实验区，避免重复三部分导航。三个栏目保留各自阅读位置。反馈链接打开预填页面地址的GitHub问题页面，由读者自行提交。

```sh
npm ci
npm run build
npm test
npm run serve
# 另一个终端中执行实际浏览器抽查
npm run accept
npm run package
```

本轮构建入口为tools/build-teacher-update.mjs，验证入口为checks/verify-teacher-update.mjs；本轮证据在handoff/teacher-update-2026-11-02。原1.13.0报告保留在handoff/teaching-map-2026-11-01。六例流程静态预览来自此前真实Chrome的默认计算；本轮沿用计算和预览，在示范里增加方法说明。

默认计算、图表及资料不需要在线模型。井见助手保留本地角色、紧凑对话和历史记录；教学展示默认加载加密后的连接配置，在浏览器解密并联网调用 Doubao Seed 2.0 mini，也可在“连接与语音”手动更换 Key。密文与浏览器解密材料一起随站点发布，属于展示用混淆；手动填写的 Key 仅保存在当前页面内存。更换展示 Key 可运行 `node tools/configure-assistant-demo.mjs`，在终端隐藏输入后重新同步构建。
