## 添加案例与离线运行

ZIP先解压，在老师原站或增强门户点击“＋ 添加案例”，一次选一个完整案例目录。录井五例在 `dist/cases/`，新增十二例在 `dist/expansion-cases/`；不要选总目录或源码目录。每例运行包恰好五个文件：

```text
case.json
README.txt
demo/index.html
demo/demo.css
demo/demo.js
```

增强门户预载十二例插件，不把预载冒充用户导入。导入相同ID的新版本时，按原案例库操作移除自己的旧包再添加。其他同学的兼容包仍使用同一入口，老师的四个导入契约文件和原样firstbreak没有改动。

双击根目录 `index.html`、门户或独立案例即可离线使用。HTTP服务只用于本地预览，不是案例后端：

```powershell
npm run serve
```

地址为 `http://127.0.0.1:8755/`。老师原站在 `/portal-original/index.html`。

```powershell
npm run build
npm test
npm run verify-delivery
npm run package
```

`build`构建五例和十二例；`test`检查原五例计算及扩展包契约；新例各自的计算检查在 `expansion-src/<scene>/checks.mjs`。没有生产依赖和CDN。
