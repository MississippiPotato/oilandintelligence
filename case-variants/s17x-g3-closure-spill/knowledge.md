# 构造图闭合与溢出点识别

案例ID：`s17x-g3-closure-spill`；绑定场景：`g3`；版本：`1.0.0`。

## 先理解什么

石油和天然气在储层岩石的孔隙中分布。比水轻的流体有向上运移的趋势，低渗透盖层阻挡向上逸散；盖层下面的空间形态决定可以在哪里聚集。本例讨论完整封盖、静水条件下的一处构造高点。

构造深度图记录同一储层顶面的深度，单位m，数值越小代表越浅。颜色表示深度，等深线连接同一深度的位置。一个局部浅点可能被更深的区域围住，也可能从侧面很快接到开放边界。只看一条东西剖面，可能没有看到北侧出口。

本页以“最后一条仍闭合的等深线”理解溢出点。闭合高度为溢出深度减去顶部深度；闭合面积是对应闭合线内与该高点相连的面积。几何闭合体积把每个格子的可容高度乘面积再求和，单位m³。它没有乘孔隙度、含油饱和度或采收率，因此不能叫可采储量。

图中的“接触面”是本例选定的水平几何充填面，表示几何充填区域的下边界，由当前充填体积求出。剖面图例中，蓝色实线为储层顶面，金色虚线为该几何充填面，朱红虚线为二维溢出深度，黑色点虚线为单剖面基线溢出深度；两种溢出深度重合时省略黑线。

## 三部分的图与操作

### 专业背景：同一个高点，侧面出口决定闭合

先并读深度地图与穿过高点的剖面：深度轴向下为正。改变北侧通道的闭合高度，再改变几何充填比例，查看接触面、着色范围和体积。图中有孔隙储层与盖层的文字说明；不把流体画成岩石内部的大湖。

默认是北侧有通道的教学顶面。东西剖面仍像完整穹隆，二维图却能沿北侧通道到达边界。封闭穹隆与整体倾斜的图幅作为另外两种对照；倾斜图可以得到零闭合，保留这一结果。

### 案例流程：逐级连通，找到第一次通向外边界的位置

1. **检查带单位的顶面观测。** 49×41个50 m×50 m格子的外缘覆盖2.45 km×2.05 km；格心间距50 m，格心跨度2.4 km×2.0 km。观测点可取50/100/200 m间隔；只使用这些点做双线性插值。输入是位置和深度，不包括参考圈闭标签。产物是插值深度图与可见采样位置。
2. **从待查点找到局部浅点。** 在8邻域中沿严格变浅方向前进，直到没有更浅邻居或到达开放边界。等浅的更浅候选按固定编号择一；平坦处没有更浅邻居时停止。产物是所选局部高点与走过的网格。
3. **寻找最容易连通外边界的通道。** 深度向下为正。候选路径的代价是该路径上最深的格子；在所有到外边界的路径中选这个代价最小者。交互逐渐增加接触面深度，显示连通区域，临界值时首次触及边界。该路径是几何临界连通路径，不表示流速或所需时间。
4. **量测闭合范围并对照一条剖面。** 严格浅于临界深度、与高点连通的格子组成闭合掩膜。计算高度、面积和几何体积；同一观测的东西或南北单剖面只沿一个方向寻找出口，作为信息较少的基线。
5. **核对出口深度与闭合范围。** 在相同比例尺、候选起点与图幅下，比较当前重建顶面和完整无噪声顶面的溢出深度、闭合范围与体积。范围交并比（IoU）为两范围交集格数除以并集格数；越接近1，范围越重合。

### 可运行示范：固定对象，单独改变一个条件

- 北侧通道：保持候选起点和噪声，改变通道高度，检查临界深度与体积如何变化。
- 采样间隔：50 m改200 m，图上采样点变少；插值可能削弱鞍部和小起伏，观察闭合误差。
- 深度噪声：固定图幅，提高观测误差，看看是否出现小的伪闭合；不保证二维法每次都比基线的体积误差小。
- 基线方向：东西改南北，同一幅图的二维结果应保持；单剖面的出口与估计体积会改变。
- 地图点选：候选点来自当前观测位置，点选后两方法从同一位置开始；开边界上的候选应得到零闭合。

## 最小算法与量测

### 观测重建

完整、无噪声教学顶面只供生成采样和评价。采样点加入固定种子的深度误差，推断通过它们的四角权重作双线性插值；缺少采样不会由参考面补值。所有采样间隔均整除48×40网格区间。

### 二维临界连通

对候选浅点a，深度为D，溢出深度为：

`Dspill = min_{P:a→开放边界} max_{i∈P} D[i]`。

优先队列从浅点出发，邻居候选代价为 `max(当前路径代价, 邻居深度)`。第一次从队列取出边界格子时，得到最小临界深度与父指针路径。只有一个候选高点，不实现论文中的全部多级圈闭合并。

闭合格子以 `D[i] < Dspill - 1e-8` 为条件，从高点连通提取；临界等深格子的厚度为0，不计入面积或几何体积。深度位于格心，每格代表50 m×50 m的面积，即2500 m²。该离散格子面积约定在全部方法与参考中一致。

`H = max(0, Dspill - Dapex)`；`A = 闭合格数 × 2500 m²`；`V = Σ max(0, Dspill - D[i]) × 2500 m²`。

充填接触面通过体积单调关系二分求解，最大只到溢出深度。超过几何闭合体积的输入作为“超出闭合体积的部分”单独显示。

### 单剖面基线

沿局部浅点所在的东西行或南北列，分别量两端到外边界的最大深度，取两条路径中较小的最大值，作为一维估计溢出深度。再用该深度计算它在当前图幅上圈出的估计范围。基线若跨入开放边界，会明确标为“剖面估计范围在二维图上已连向边界”；不把这个体积当已封闭容量。

这是一项教学对照，不声称是行业标准储量评估方法。默认通道在北侧时，南北剖面可能接近二维结果，东西剖面可能高估。

## 观测、推断与评价的边界

- `generate()` 返回分开的 `observations` 与 `evaluationTruth`。观测含位置、采样深度和尺度，候选起点通过独立config显式输入；参考面不放进观测对象。
- `infer(observations, config)` 与基线不读取evaluationTruth；用户点选和参数均是显式输入。地图预测层不按参考类别着色。
- `evaluate(inference, evaluationTruth, config)` 在预测后计算：溢出深度绝对误差（m）、闭合掩膜IoU、几何体积绝对/相对误差。inference含二维预测与单剖面基线。参考无闭合时相对体积误差为NA；两掩膜都空时IoU为1，并显示零闭合背景。
- 本例采用固定种子的合成顶面，以规则采样和双线性插值形成观测；完整无噪声顶面在计算后用于比较。深度、闭合量和充填面均来自该教学模型，评价用于观察采样密度和深度误差怎样改变闭合认识。
- 数值检查另用手工网格和“逐个深度阈值做连通搜索”的独立算法核对临界出口，不以对同一算法的自我比较代替正确性检查。
