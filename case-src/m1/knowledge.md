# m1 岩屑识别：先看清一粒，再说清一盘

面向没有石油背景的本科生。核心认识：**岩性候选应当能回到可见的颗粒和相似样品；统计一盘岩屑时，还必须说清分母。**

## 三个学习结果

1. 说清岩屑从井底到样品盘的来路，并能指出砂岩、页岩和灰岩照片中值得观察的线索。
2. 把颗粒轮廓、颜色和纹理联系起来，解释泥浆附着或照明改变后，为什么机器判断也可能改变。
3. 从同一盘计算结果读出颗粒数比例和可见面积比例，说明两者为什么不同，并保留待复核部分。

## 知识单元一：井底的岩石，怎样来到样品盘

**白话解释。** 钻头钻碎岩石，产生的碎片叫“岩屑”。钻井液沿钻杆向下、从钻头流出，再沿钻杆外侧的井眼空间返到地面，将岩屑带回。“振动筛”把碎片和液体分开，录井人员对样品适当清洗、整理，再用放大观察辨认岩石。地下取出的一长段较完整岩石叫“岩芯”，它与破碎、搬运过的岩屑形态不同。地面取到样品的时刻晚于井底破岩时刻，因此样品身份和来源井段应随照片一起保留。[S1][S2]

**对应图。** 开场纸本微缩画卷呈现井底破岩、携屑返出、筛分取样、观察归档四个区域；它只帮助定位材料的来路。正文采用紧凑的采样带示意，将照片观察和后续逐粒计算接起来。

**读者操作。** 点击画卷的“筛分与取样”，定位文字；在主演示观察同一盘白光像素，并点击一个轮廓。

**应看到的变化。** 点击会改变当前研究的颗粒，图像坐标、轮廓、特征和近邻同时对应这个对象。照明或附着变化时，保留这个像素锚点；若该处不再有轮廓，明确显示原位置，不换成另一粒。

## 知识单元二：先认识岩石，再理解外观线索

**白话解释。** “岩性”在这里是岩石类型的描述。砂岩是砂粒等被天然胶结物固结起来的岩石；页岩由细粒沉积物组成，页理是较薄的层状构造，常沿薄层劈开；灰岩主要由方解石等碳酸盐物质组成，方解石是一种碳酸钙矿物，灰岩外观可细密，也可见颗粒或化石结构。不同岩性可能颜色相近，同种岩性也能有多种颜色，不能用“黄色就是砂岩、灰色就是灰岩”代替观察。[S3][S4][S5]

**对应图。** 六张真实 2×2 cm 岩芯照片按发布者标签成对排列，读者能比较同类内部的变化，再看三类间的差异。图注逐类指出“看哪里”，不把照片当作演示的训练样本。[S6]

**读者操作。** 点选砂岩、页岩或灰岩照片，再切换同类第二张；读旁边的观察提示。照片保持发布者的 shale／页岩名称，实验的“泥岩教学外观”则是给合成盘中细粒层状纹理取的教学分组名，没有把真实照片改标。页岩的薄层劈开特征需要具体岩石证据，不能只凭合成纹理把两词互换。

**应看到的变化。** 选中的真实图像与观察提示一起更新；它支持认识地质线索。主演示使用一盘单独生成的教学岩屑，研究分割和分类方法；没有把六张岩芯照片拼接成带逐粒真值的分类实验。

## 知识单元三：机器先找轮廓，再比较颜色和纹理

**白话解释。** “分割”是从图中找出属于岩屑的像素。“连通域”是相邻前景像素连成的一块；本例用它作为一个检出颗粒。泥浆遮住岩屑或两粒碰在一起，轮廓就可能缺失或合并。RGB是红、绿、蓝三个颜色通道，每个通道值为0–255。“特征”是从轮廓内像素计算的描述，例如 RGB 均值、明暗差异、邻近像素的变化及外形紧致度。颜色会受照明影响，纹理补充了颜色看不出的信息。[S2][S7]

“参考片校正”是在图中放置目标颜色已知的小片，根据实测颜色校正三个通道。本例保留已知灰片；校正不会补回被泥浆挡住的纹理，也无法恢复已经过曝截断的颜色。实际工程中的定量颜色采集也依赖控制照明、校准和拍摄元数据。[S8]

“k 近邻”把当前颗粒与已有标注颗粒的特征比较，k是选取的参考颗粒个数，距离越小表示这些特征越相似。选出最近的 k 个参考样本后，以距离加权形成候选。不同特征先用训练组均值和标准差调整尺度。支持度表示近邻投票中支持候选的份额，不是现场正确概率。颜色、纹理和形状进入16维分类距离，绝对像素面积则单列用于整盘汇总。只有颜色规则的基线使用同一批检出轮廓，便于观察加入纹理等信息后的改变。

**对应图。** 同一盘原图与轮廓图并排；静态讲解图在实际颗粒局部画出扫描线，亮度曲线只取连通域内像素，遇到背景断线。演示选中轮廓后给出局部像素、颜色／纹理读数、实际训练库前三近邻和距离。规则与多特征结果同屏。

**读者操作。** 拖动照明、增加泥浆附着，观察同一教学盘的位置及近邻。附着控件表示教学图像的覆盖强度。另可选“重排教学盘：中排靠拢”比较另一幅摆盘情景；所有改动自动重算，固定当前像素锚点。

**应看到的变化。** 输入像素、参考片读数、轮廓和候选更新。若原位置失去轮廓，保留虚线定位并停止呈现该位置的近邻。切换重排教学盘后，显示“颗粒身份未确认”：固定坐标只用于位置对照，新轮廓与旧区域相交时呈现观测轮廓的空间交叠，不由此确认同一物理颗粒。点选新盘区域后，再围绕这次选择研究其照明或附着变化。

## 知识单元四：同一盘，为什么有两个比例

**白话解释。** 按颗粒数统计时，一粒大岩屑与一粒小岩屑各算一个；按可见面积统计时，较大的图像区域权重更大。例：一粒大砂岩外观占 200 像素，四粒小泥岩外观各占 20 像素，砂岩的颗粒数比例是 1/5=20%，可见面积比例是 200/280≈71.4%。两种统计回答不同的问题。

实际演示的“颗粒数分母”是所有检出轮廓的数量；“面积分母”是这些轮廓覆盖的可见像素之和。待复核单列并保留在两个分母中。图像面积没有测到隐藏部分、厚度或密度，因此直接读作“这一盘图像里的可见面积比例”，不改写为地层质量或体积比例。采样整理也可能改变颗粒大小的代表性，解释时应回到采样条件。[S2]

**对应图。** 上下两条百分比带使用完全相同的类别顺序和颜色，分别注明各类分子及整盘分母；并列显示颜色规则与多特征方法。小示例解释两种分母，实际带图由当前轮廓逐粒累加计算。

**读者操作。** 切换被选颗粒，看它在“数量一票”和“面积若干像素”中各占多大；改变附着或靠拢后再次比较分母。

**应看到的变化。** 轮廓少了或合并了，颗粒数分母随之改变；可见像素也可能改变，两条统计同时更新。待复核不会被删除后重新凑成 100%。

## 案例流程与当前对象的产物

| 步骤 | 输入 | 实际动作 | 当前产物 |
|---|---|---|---|
| 样品登记 | 样品身份、白光像素 | 保留样品与拍摄对应 | 身份键、320×240 图像、当前锚点 |
| 参考片校正 | 原图、灰片区域和目标颜色 | 逐通道求均值并校正 | 实测 RGB、校正后图像、质控提示 |
| 颗粒分割 | 校正像素 | 前景距离阈值、四邻域连接 | 实际轮廓数量、选中区域面积、消失／合并提示 |
| 特征描述 | 当前轮廓内像素 | 算颜色、纹理、形状，共16维 | 数值和对应图像局部 |
| 近邻与基线比较 | 训练库、当前特征 | 标准化距离和加权投票；同轮廓跑颜色规则 | 实际邻居、距离、候选、支持度 |
| 双口径汇总 | 全部检出轮廓与候选 | 按个数和可见像素分别累加 | 各类分子、两个分母、待复核份额 |

## 数据与计算边界

- 真实照片：Mendeley Lithology dataset V1 中现有六张原 JPEG，照片来源与 CC BY 4.0 署名保持可查。原数据包括 sandstone、limestone、shale 及垃圾类，页面仅选现有三类照片各两张。[S6][S7]
- 主演示：沿用 `S17Images.sample` 和 `M1Core`；训练、验证按完整托盘分组。预测只用 `observations` 和已拟合训练库，完成后才调用独立评价。
- 计算结果和导出继续保存独立评价、匹配漏检／合并、基线及完整设置；教学界面聚焦观察、方法依据和统计口径。
