# m3 荧光判读：先辨观察条件，再量显示范围

版本：1.7.1。核查日期：2026-10-29。读者：没有石油背景的本科生。

核心认识：**紫外光下哪里发亮、亮了多大一片，需要在同一样品、同一可见范围和明确曝光条件下比较；发光的区域还需要结合矿物和钻井液信息解释其来源。**

## 三个学习结果

1. 能说明白光观察与紫外观察各看什么，并用方解石实例解释“发光不能直接认定为油气”。
2. 能区分样品本身的显示与拍摄曝光的影响，指出参照片能帮助校正什么、过曝会丢失什么。
3. 能用“检出显示的像素数 ÷ 可见岩屑像素数”读懂面积比例，并解释三种方法为什么必须在同一范围上比较。

## 单元一：岩屑为什么要换一盏灯看

- 白话解释：钻井液把井底破碎岩石带到地面，录井人员取样观察。普通白光有助于看颗粒位置、外形与岩石外观；紫外光照射后（短波和长波表示激发波段不同），有些物质会发出人眼可见的光，这种现象叫荧光。它补充白光观察，帮助寻找值得进一步检查的显示。
- 首次术语：**岩屑**是钻头破岩形成的碎片；**UV**是紫外光；**荧光**是物质吸收激发光后发出的光；本例的**显示**指图像中被观察或检出的发光区域。
- 对应图及认识：地面白光观察台与遮光 UV 检查台的宏观画卷定位；真实方解石白光照片与短波 UV 照片并排，支持“同一块样品在不同照明下提供不同线索”。图不绘制油藏结论。
- 读者操作：在真实照片中切换短波／长波 UV，始终保留白光参照。
- 应看到的变化：相同形状与位置的标本呈现不同颜色；照片原出处说明这是同一组方解石标本。
- 专业依据：[S1] 取样与 UV 检查；[S2] 荧光定义；[S3–S5] 同一组真实标本及照明条件。

## 单元二：发光区域不是“油气区域”的同义词

- 白话解释：油、部分矿物以及某些钻井液添加物都可能产生荧光。因此先记录颜色、强弱和分布，再结合岩石、钻井液和进一步观察判断来源。真实方解石在 UV 下发光，正好让读者看到矿物也能成为发光源。
- 首次术语：**矿物**是组成岩石的天然物质，方解石是一种常见矿物；**配对图像**指同一样品在两种照明下取得的图像，样品身份和对应位置能够对上。
- 对应图及认识：同一框线在白光、UV 照片中标出同一标本；旁列“看到发光→记录位置与范围→核对来源”的观察关系，支持“先描述看到什么，再解释来自什么”。
- 读者操作：点击真实照片选择同一区域，框线在另一张照片同步出现。进入主演示时先核对样品编号和白光轮廓。
- 应看到的变化：变的是观察方式，样品位置保持对应。照片仅用于认识矿物荧光；它们没有逐像素油气标签，不参加本例分类性能计算。
- 专业依据：[S6] 矿物及钻井液添加物的影响；[S7] 荧光与溶剂观察的联合使用。页面讲来源核对，不提供化学实验操作教程。

## 单元三：曝光会改变“看起来有多亮”

- 白话解释：**曝光**是相机接收光的程度。拍得更亮，简单亮度阈值可能把更多像素划成显示；拍得很暗，弱显示可能丢掉。画面中的**参照片**是一小块已知参考响应的区域，配合暗背景估计拍摄增益，帮助把不同曝光下的数值放到可比尺度。像素达到相机最大值叫**饱和**，此后提高真实亮度也不会让记录数值继续增加，细节已经丢失。
- 对应图及认识：固定白光样品，UV 图随曝光变化；参照片外置说明数值；原亮度阈值与参照校正阈值并排。支持“亮的变化可能来自拍摄，校正需要参照，过曝无法靠重新缩放恢复”。
- 读者操作：把曝光从 1.0 调到 0.5、2.0，再到 4.0，观察三种方法的检出像素和质控提示；复位回到 1.0。
- 应看到的变化：白光决定的可见范围和分母保持相同；UV 像素与原阈值结果改变；校正结果在未饱和范围内相对稳定；4.0 时参照片饱和，界面解释校正依据受损。
- 计算依据：现有 `M3Core.prepare()` 使用同一白光分割得到 ROI，以 UV 参考片与暗场校正通道；`M3Core.infer()` 真正逐像素计算三个掩膜。该受控变化由原教学数据生成器提供，固定 UV 激发，不把不同波长真实照片做成曝光校正实验。

## 单元四：先统一分母，再比较方法

- 白话解释：图像分割是给像素划分区域。首先用白光确定看得见的岩屑范围，称为 **ROI（本例的可见岩屑范围）**；然后只在这个范围内找显示。**显示面积比例 = 检出显示的像素数 ÷ 可见岩屑像素数**。托盘背景不进入分母。一个像素是图像的一个小格，本例同一张图上的每个像素面积相同，因此可以按像素计数。
- 三种方法：①原始 UV 的平均亮度超过固定值；②参照校正后的平均亮度超过同一值；③学习方法先用训练样品的均值与标准差统一五项特征（校正后的红、绿、蓝、颜色差、邻域反差）的尺度，再乘以学到的权重并求和，把总和映射成0到1的显示得分，这称为逻辑回归。得分达到验证阶段选定的阈值才划入显示；两个亮度方法均以45为界。**得分不是含油概率或油气来源概率**，它表达本教学分割任务中的显示倾向。
- 对应图及认识：同一 UV 图上的半透明掩膜和外轮廓；三行同一分母的面积条与实际计数；得分图选点显示该像素真实特征与得分。支持“方法改变的是选入哪些像素，面积解释必须交代数出来的分子与分母”。
- 读者操作：在三方法之间切换，或切换叠加图／得分图；得分图始终显示学习法，色标标出实际阈值；点击一个像素，核对它是否在可见范围、各方法是否选中以及显示得分。
- 应看到的变化：选中方法、掩膜边界和分子同步改变；同一样品的分母不变。图下说明该面积是二维可见表面上的显示占比，不直接等同于岩石含油饱和度。
- 计算依据：训练只接收独立教学训练样品，验证样品选择阈值，当前样品预测只读取观测图像；评价真值只传给独立 `M3Core.evaluate()`。默认演示不展开训练参数和完整指标，检查接口及保存结果仍包含它们。

## 案例流程与每步产物

| 步骤 | 当前输入 | 实际动作 | 计算产物 |
|---|---|---|---|
| 白光／UV配对 | 当前样品的白光、UV、样品编号 | 固定样品身份与图像坐标 | 一组可对应的图像及当前选点 |
| 曝光与质控 | UV像素、暗背景、参照片 | 估计校正尺度并数饱和像素 | 参考RGB、暗场RGB、饱和计数、质控提示 |
| 像素特征与模型得分 | 可见范围内的五维像素特征 | 用独立训练得到的逻辑回归计算显示得分 | 当前像素五项特征、真实得分、固定选择阈值 |
| 显示分割 | 三种方法的数值与阈值 | 每像素形成0/1显示掩膜 | 三张掩膜及选中轮廓 |
| 同范围方法比较 | 三张掩膜与共同可见范围 | 使用相同分母统计 | 三组显示像素数、共同分母和面积比例 |
| 面积与来源核查 | 当前范围、条件、显示计数 | 将面积描述连回样品及观察条件 | 有来源的面积陈述与保存结果 |

## 数据和图片角色

- **真实专业观察**：Herbert Art Gallery and Museum, Coventry 同一组方解石白光／短波 UV／长波 UV 照片。原图在项目 `data/real/images/calcite-*.jpg`；页面使用已有缩小编码副本以便离线阅读，保留颜色，未把其当作石油岩屑。署名与 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 随页面显示。
- **实际算法演示**：原 `S17Images.sample()` 可控教学配对图像。模型用12个独立教学训练样品训练、4个验证样品选择分割阈值，默认测试样品 `DEMO-017-P1` 独立。曝光改变时固定随机种子、样品编号和白光内容。
- **显示计量**：页面的每个面积、参考值、饱和数、得分和轮廓来自当前计算；没有预写随滑杆变动的结论。完整评价与来源在 `S17Inspect` 和小型保存入口保留。
