[ ] 独立双击demo/index.html运行；断网后默认功能与图表可用；沙箱内下载测试通过。

二、每例通用质量
[ ] 一个明确业务问题；数据形态、实际算法、数据性质在页面可见。
[ ] 背景每图解释一个专业概念，有单位/图例/假设，至少两至三图。
[ ] 流程每步有输入、动作、输出、图解和陷阱；图号与演示对应。
[ ] 演示真实计算，不用计时器或预存结论冒充执行。
[ ] 同一测试数据上运行基线与模型；差异归因明确，不保证模型必胜。
[ ] 至少一个失败/边界预设与人工复核动作。
[ ] 输入改变使结果stale，重算完成才可导出当前结果。
[ ] 预测可见输入与评价真值隔离；测试标签、生成器隐藏属性不进入模型。
[ ] 按井/样品/事件/模板族分组；同源变体不跨集合。
[ ] 标准化等预处理只在训练拟合；阈值/超参数使用验证，测试交互标为探索。
[ ] 指标由实际预测计算，分母明确；无接受样本/无事件等空集显示不适用。
[ ] 未校准得分标支持度，无根据不显示概率或置信区间。
[ ] 人工修改与模型原结果分开留存；数据合成标记在结果附近。
[ ] 所有输入都有恢复默认、有效范围或明确错误提示。
[ ] 深度向下、时间向右、单位一致；重要信息不只靠颜色；窄屏/键盘关键操作实际检查。

三、五例专门检查
m1：
[ ] 颗粒轮廓与特征来自真实像素，近邻来自实际训练库。
[ ] 计数/二维面积分母清楚；待复核仍在总分母里。
[ ] 分类评价区分分割漏检/合并；拒判不静默删除。
[ ] 照明、遮挡、陌生纹理真实改变像素与结果。
[ ] 父样品与白光/UV配对身份可与m3核对。

m2：
[ ] 停泵期间累计有效泵量不推进；恒流能与V/Q解释一致。
[ ] 来源时刻查询MD(t)，不以当前ROP×延迟替代。
[ ] 候选事件检测一对一匹配；漏检/多余候选独立报告。
[ ] 解释混淆有拒判列；覆盖率和接受集错误率同时显示。
[ ] 工况缺失/重叠不输出过度确定结论。
[ ] 源深度误差仅在确有适用真值的情景统计。

m3：
[ ] 固定激发条件，参考校正与学习增量分开比较。
[ ] 饱和图提示不可恢复细节；没有跨波长校正的虚假说法。
[ ] 评价区域预先固定，不以预测ROI缩小评价分母。
[ ] 矿物等发光仍为荧光分割真阳性；来源解释单独待核查。
[ ] 教学等级的预测/参考均用同一透明规则分别处理预测/真值。
[ ] 面积占比不改称含油饱和度或储量。

m4：
[ ] ROP与钻时的倒数只用于同一有效钻进区间；停钻无效值处理。
[ ] 工况模型在独立同岩性标定数据拟合，未利用测试地层变化。
[ ] 聚类中心由训练数据学习，测试不使用隐藏边界。
[ ] 固定地层改变工况、固定工况加入薄层两项实验均可运行。
[ ] 边界一对一容差匹配；假边界和薄层漏检可定位。
[ ] 输出候选响应段，聚类编号不直接等同真实岩性。

m5：
[ ] 六类NB真实计数/推理，关键词基线共用后续抽取与模板。
[ ] 否定、数值+单位、时间/深度作用域保留，缺项不补造。
[ ] 句子能定位具体来源ID/版本/范围，不只有一个泛链接。
[ ] 来源关联不等于语义已核对；观察、推断和人工确认区分。
[ ] 修改句子或来源后同时撤销当前复核/追溯/支持状态，保留历史。
[ ] 自由文本无金标不显示准确率、事实覆盖率、无依据断言性能。
[ ] 原文存在不保证自由改写受支持；自动无法核对时转人工。
[ ] JSON/HTML导出携带来源版本、限制和状态；用户文本不作为HTML执行。

四、必要且有意义的计算验证
使用小型手算fixture验证F1/混淆、IoU、事件/边界一对一匹配；空集/全拒判明确输出。
对迟到映射验证恒流、停泵再开、无足够累计体积三种情况。
对m5验证“未见明显荧光”“未见荧光，但气测升高”、缺单位、同句多范围、源版本变化。
检查固定种子复现；改变evaluationTruth不会改变预测但会改变评价。
不为静态文案/颜色等低影响修改堆叠镜像测试；检查只为解决具体风险或必要门槛。
