# 井见助手 · 浏览器解密演示连接 · 2026-11-02

按用户明确选择实现前端解密、自动连接，用于老师展示。使用当前提供的 Key；未调整其账户额度。未新增或恢复云端代理，也不需要新的平台账号。

## 实现

`tools/configure-assistant-demo.mjs` 在 Node 构建环境通过隐藏终端输入读取 Key，以 AES-256-GCM 加密：32 字节随机密钥、12 字节随机 IV、128 位认证标签，并绑定版本附加数据。生成的配置只含密文及浏览器解密材料，不含原始 API Key 文本。配置在静态站点和各例包中自包含。

`s17-volcengine.js` 使用浏览器 Web Crypto 解密，在内存中配置现有模型适配器。页面打开及刷新后自动就绪，首次实际请求成功后显示“在线”。保留手动覆盖、断开当前连接和恢复演示连接；手动设置优先于尚未结束的自动解密。输入框不回填解密结果。

这是构建时加密、浏览器解密的静态演示方案，没有声称 GitHub Pages 执行后端代码。解密材料按用户要求随前端发布，具有可恢复性；未作“不会被扫描或停用”的保证。无需再把明文 Key 写进源文件或构建命令参数。

## 浏览器与实际接口

- 本机 Chrome 自动解密并调用火山方舟 Responses API，HTTP 200。文字请求首个增量约 2326ms，收到 86 个增量片段，完成耗时约 2981ms。完整回复及用量见 `live-text.json`。
- 图片真实调用成功，识别井架与荒漠地表，收到 55 个增量；音频文件真实调用成功，复述了“气体从井底到地面为什么需要时间”，收到 13 个增量。见 `browser-media.json`。音频输入测试采用此前生成的中文语音 WAV，没有宣称实体麦克风已验证。
- 验证刷新自动恢复、历史保留、手动覆盖、自动解密竞争时手动优先、断开后不立即重连、恢复演示、空白密码框、390px 窄屏、独立 m2 以及断网 file:// 下计算仍可运行。见 `browser-ui.json`。
- 加密往返、认证标签及篡改密文拒绝、公开文本文件中无原始 Key 的扫描分别记录于 `encryption-checks.json`。这些属于源码与加密检查，不替代浏览器调用结果。

## 复现

1. `node tools/configure-assistant-demo.mjs`，在隐藏终端输入新 Key。
2. `node tools/sync-assistant.mjs --base=2e896ce --report=handoff/assistant-demo-2026-11-02 --revision=0.8.1`。
3. `node checks/verify-assistant-sync.mjs handoff/assistant-demo-2026-11-02` 与 `node checks/verify-assistant-demo.mjs`。
4. 启动本地服务后，通过 `node tools/pw.mjs jingjian-demo open http://127.0.0.1:8755/portal/index.html --config checks/playwright-local-file.json` 打开 Chrome，再运行 `node checks/browser-assistant-demo.mjs ui`；`media` 会实际调用模型并使用额度。
