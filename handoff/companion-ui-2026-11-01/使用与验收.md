# 常驻 Live2D、紧凑对话与案例阅读导航

日期：2026-11-01。本轮修改助手和阅读容器，保留已有五个录井案例修订、65个案例的计算前缀和老师原站副本。

## 已实现

- Live2D在进入首页、案例页等门户路由后自动加载，本地资源异步读取。嵌入案例由外层门户持有一个人物，内层不重复请求模型。
- 常驻人物由旧的62px入口放大到桌面174×186px、手机136×148px。保留主动最小化为44px按钮的入口。
- 移除人物旁邀请卡片。打开后的主面板宽352px，空对话面板约183px高；连接、历史、附件、录音、朗读和新对话仍在同一面板内。没有回复时不展示介绍卡片，有实际回复后在面板内显示。
- 门户内只显示实验区，去掉重复标题、三部分导航和背景/流程内容。实验区高度随图表、控件和展开内容变化，内层不再出现纵向滚动条。案例独立打开时保留原导航。
- 专业背景、案例流程、可运行示范分别保存阅读位置，首次进入到页面顶部；切回或刷新可恢复。章节检索深链仍定位知识标题。
- 示范内部“查看流程”等入口会切换外层栏目；示范内Ctrl/Cmd+K可以打开门户检索。

## 设计参考

查阅了[Live2D Widget](https://github.com/stevenjoezhang/live2d-widget)、[Framer Chatbot Assistant](https://www.framer.com/marketplace/components/chatbot-assistant/)的文档和实际预览，以及[UNITH数字人嵌入文档](https://docs.unith.ai/customising-the-legacy-embedded-digital-human)。采用人物常驻、面板按需展开和视口内收纳的组织方式。保留本站角色、配色和本地资源，未引入这些服务或其付费组件代码。

## 证据分开记录

- `build.json`：65个案例计算前缀、130个JSON/README文件保持本轮开始时的内容；65个HTML只给本地脚本和样式增加版本参数，去除该参数后页面字节与原来一致，避免线上沿用旧缓存。全部325个运行文件仍符合五文件/6MiB限制。770个专业源码及原站保护文件与本轮开始时一致。
- `source-checks.json`：1234项源码、语法、索引和文件检查通过。这条命令没有操作浏览器；新记录保存在本目录，旧的构建和验收锁未回写。
- `browser.json`：Chrome实际36项通过。覆盖自动启动、放大入口、空对话、实际导览回复、历史、连接设置、最小化、390px排版，以及g1/m1/m2/co3四种案例布局的嵌入。四例内层导航为零、重复人物/模型请求为零，iframe视口高度等于内容高度。
- `browser-scroll.json`：额外3项实际操作通过。滚轮位于实验内时外层页面从700滚到1150；切换回来及刷新后恢复1150。背景、流程分别恢复780和560的记录在主浏览器文件中。
- `compatibility.json`：实际12项通过。断网file页面自动加载人物，独立案例保留导航，修改阴影后重新计算并实际下载JSON；增强门户file示范可进入实验，流程入口切换外层栏目。老师原站目录导入、流程、示范、刷新及修改重算通过。

资源版本参数增加后，脚本与样式内容未再改变；离线与老师原站导入单独重新执行兼容协议。

本轮浏览器范围为上述抽查，没有声明全65例逐项浏览器验收。模型服务连接协议没有改动，本轮没有使用在线模型或填写真实API Key。

## 修复和保留的过程记录

- 初次自动启动时，内层偶尔先请求了一个PIXI脚本；通过明确的嵌入模式在请求前禁止内层人物加载后修复。
- 连续阅读布局用高优先级样式保持背景可见，曾盖过嵌入模式的隐藏规则；嵌入时对非实验兄弟节点使用局部样式后修复。
- 人物尺寸还会受到知识稿内旧样式影响。截图复查发现后，提高组件范围选择器优先级，并为四种阅读页及手机补充尺寸复验。
- M2的“查看六步”按钮属于实验内跳转，并非第二套导航；现转发到门户流程栏目，避免进入已隐藏的内部章节。
- 构建脚本曾与源码检查共用`runtime-lock.json`，导致再次同步时读取了不同格式。助手同步记录现放在`assistant/`子目录，源码/运行锁独立。
- `0.50`在Chrome范围控件中会被规范化为`0.5`，浏览器工具把前一种文本视为非规范值。协议已改用`0.5`；这是操作格式修订，未改计算代码。

## 重建与交付

运行`npm run build:companion`更新界面层，运行`npm test`核对文件及冻结范围。`checks/companion-ui.browser.js`、`checks/companion-compat.browser.js`由仓库的Playwright CLI封装实际执行；保存的JSON与源码检查不是同一类证据。

`npm run package:companion`检查当前文件指纹及浏览器结果，生成本日65例合集和完整离线网站，逐个验证ZIP成员CRC及SHA-256。历史压缩包保留原日期和原范围。本轮开始前已有的录井修订记录仍在`handoff/mudlogging-refinement-2026-10-30/`，本轮不回写其中原有验收结论。
