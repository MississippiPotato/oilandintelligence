## 明确没有验收的内容

本轮模型请求使用接口替身验证真实前端请求形状和响应解析，没有调用真实付费在线模型。图片确实解码，WAV确实经过本地音频准备并进入当前轮请求；历史只留下名称。朗读验证使用浏览器语音方法的替身与实际按钮、嘴型状态，未验证实体麦克风录制或扬声器发声。短视口检查模拟软键盘可用高度，不等于实体手机软键盘验收。

HTTPS/localhost提供IndexedDB持久会话。老师原站的不透明沙箱无法持久保存，历史入口明确提示内存模式；不修改原站或放宽沙箱。file存储是否可用取决于浏览器，本次Chrome实际为persistent。

## 运行与复查

- npm run serve：本机8755端口。
- npm run build:assistant：只同步共用助手，不重建案例内容。
- npm run accept:assistant：三个浏览器阶段及当前助手范围检查，需要先运行本机服务。
- npm run verify:assistant：当前文件锁、教师副本、助手脚本与浏览器报告核对。
- npm run package:assistant：生成本轮两个ZIP，并逐成员检查CRC和SHA-256。

已有课程阶段的历史报告和旧ZIP保留原日期。本轮不声称全61例重新通过所有浏览器路径，也没有重新发布GitHub线上站点。
