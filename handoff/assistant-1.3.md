# 首页多模态助手 1.3.0-preview

2026-10-23。本轮新增首页交互，五个成品案例保持v1.1.0，25文件不变；老师两份原站共46文件按原锁核对。没有扩展其他56例，没有新增训练、等级模型或科学性能实验。

## 页面现在能做什么

- 官方Live2D角色改为Jin Natori（名取仁），西装外套、衬衫与长裤。运行库和角色全部本地；模型、原纹理、表情、三个待机动作、来源哈希和许可分开保留。
- 本地导览和受限导航可到首页、作业链、录井阶段、m1–m5及真实荧光对照。模型可返回同一组导航目标；由页面显示按钮，用户点击进入。
- 接入豆包Mini260428 Responses API。支持文字、一张图片及一段音频同时输入。图片≤5MB，录音文件≤8MB且≤60秒。浏览器将音频解码并转为16kHz单声道PCM16 WAV。
- 支持麦克风开始/停止、试听、移除。点击发送才上传；失败保留，成功清空。后续轮次不自动重传二进制，仅保留附件名称；需要再看原文件时重新附上。
- 支持手动或自动系统朗读与简单嘴型动画。收起时取消请求、停止系统朗读、停止并丢弃正在录制的音频。
- Key只在当前页内存，启用后立即清空密码输入框；不写源码、配置、日志或浏览器持久存储。刷新重新填写，断开主动清空。

录音流程检查使用Chromium模拟音源和实际MediaRecorder/WebAudio编解码，不使用人的实体麦克风。真实API的WAV由本机Windows System.Speech生成，文本与来源随output/assistant-fixtures保留。没有录制用户声音。早期两次补充脚本分别遇到测试上下文中已有同ID包、误把原站按钮写为链接；失败记录attempt1/attempt2保留，最终脚本在独立的自动化浏览器上下文清空测试存储后按实际按钮执行。

## 仍未验收或未建设

- 火山原生语音输出、云端TTS、端到端实时语音没有接入。当前Mini接收音频、返回文字，朗读是浏览器/系统功能。
- 官方API支持视频输入，本轮页面没有视频上传入口。
- 实体麦克风、实际扬声器听感、其他浏览器和真机手机未验收；390px与横屏为桌面Chrome视口检查。
- 没有共享Key服务或自动记住Key。联网模型只是离线教学站点的可选功能；file离线可显示角色与本地导览，不能离线调用云模型。
- 模型只收到页面元数据及用户本轮明确附上的文件，未自动读取案例iframe内实时曲线、预测或评价真值。导航只接受本站允许目标。

## 打开与操作

解压1.3预览总包，直接打开portal/index.html可看角色与本地导览。要录音，建议在本目录运行`npm run serve`，打开http://127.0.0.1:8755/portal/index.html。展开“模型连接与语音设置”，填写自己的Key，启用后提问或发送附件。模型调用需要网络。五例仍通过老师原站“＋ 添加案例”逐例导入完整文件夹。

原1.1五例ZIP、1.2助手ZIP和相应历史记录保留；1.3总包单独命名。
