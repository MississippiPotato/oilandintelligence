# 12 阶段扩展案例独立审阅口径

审阅日期：2026-10-24。范围为用户本轮明确选择的其他 12 个阶段各 1 例：g1、s1、d1、w4、c1、co1、p1、pr1、wo1、e1、t1、r5；不将原有录井五例、老师原样例或其他 44 个场景计入新增数量。

本审阅只新增本目录下 review 开头的报告。作者负责代码与修复，主智能体负责浏览器导入和离线验收。以下是审查规则，尚未代表任何案例已通过。

## 依据及优先顺序

1. 用户转述的老师最新要求：专业背景、案例流程、可运行示范三部分均应有充分可视化；明确石油场景与智能方法的结合；纯前端；原添加案例入口兼容；互动产生可观察的计算结果。
2. `s17_development_kit/03_extra_56_cases.json` 中选定的 12 张任务卡；任务卡仍是方案，不是现有成果。
3. `s17_development_kit/06_兼容与验收清单.txt` 和 `07_证据交换与数据协议.json` 的真实计算、评价隔离、状态与证据约束。规则型 co1 不要求虚构训练或损失。
4. 原站 `firstbreak-pick-case` 及当前五例的实际结构确定上传契约。没有真实浏览器证据的条目只记源码或计算检查，不记浏览器通过。

## 每例都要审查

| 维度 | 实质检查 | 证据性质 |
| --- | --- | --- |
| 专业对象 | 背景至少 3 张目的不同的概念图；术语、物理量、单位、图例明确；图示确实解释场景 | 源码与成品内容 |
| 流程 | 每步有输入、动作、产物、对应图解和具体陷阱，图形不只换标题 | 源码与成品内容 |
| 方法 | 模型实际拟合或知识规则实际执行；基线、指标来自同一批观测，指标分母清楚 | 实现审查、轻量计算 |
| 数据隔离 | 独立井/剖面/地理块/文档族或前推时间切分；预处理只拟合训练；验证选参数；预测不读取测试真值 | 调用路径、真值扰动检查 |
| 交互 | 边界预设真实改变输入数据；拒判、错误、空集有实际表现；人工意见独立于原始预测 | 实现审查；浏览器由主智能体执行 |
| 当前状态 | 输入变更后 stale，当前导出禁用；复核失效，历史保留；导出携带数据、参数、来源、版本、结论和状态 | 状态调用路径、计算检查 |
| 兼容 | 唯一 ID、合法 sceneId/methods、三标签、普通 IIFE、文件自包含、无 CDN/密钥/后端依赖、不读父站私有存储 | 源码与成品结构 |
| 真实性 | 不固定成绩，不保底“模型更好”，不把教学指数写成现场量，不将检索或推断写成现场结论 | 可见文案、计算结果 |

## 各组重点风险

| 案例 | 特别需要核对的风险 |
| --- | --- |
| g1 地质遥感 | 多波段/纹理必须来自可见像素；地理区块留出；阴影真实影响像素；分类地表单元不推断储量 |
| s1 地震断层 | 反射同相轴错断与局部缺失区分；特征来自地震剖面；掩膜或迹线评价与真值独立；单位/容差清楚 |
| d1 钻速 | 代理回归与合成响应函数分开；留出工况误差；可行域搜索与被剔除原因；目标不偷用测试真值 |
| w4 测井 | 与岩屑图像区分；整口井切分；训练标准化；深度向下，多通道开关确实改变推理输入 |
| c1 固井 | 套管、水泥环、地层与声波解释连贯；CBL/VDL 观测是真正输入；偏心因素不是隐含标签；不直接宣布井筒完整性 |
| co1 完井 | 显式条件传播、冲突排除、排序；基线同样接受约束评价；不虚构学习；未知关键条件不得自动作为满足 |
| p1 射孔 | 射孔几何有清楚物理对应；学习代理与合成性能函数独立；按岩性/参数块留出；约束变化真实改变候选 |
| pr1 示功图 | 位移—载荷闭合循环与泵动作有关系；归一化及形状特征真实计算；独立循环来源；噪声/偏移不是改答案 |
| wo1 修井 | 词项/IDF 来自训练文档；井史/文档族留出；检索候选与知识约束可定位出处；缺信息时不越级给具体作业步骤 |
| e1 增采 | 压裂几何及资源意义清楚；代理误差与约束分开；独立储层/设计块；推荐仅为当前约束下教学候选 |
| t1 输送 | 正常压力—流量模型只拟合正常训练工况；负荷/漂移与泄漏区分；事件匹配一对一；检测延迟只统计适用匹配 |
| r5 加工 | 化验采用“到达时刻”而非取样时刻；特征预测时可知；时间前推隔离；最近已到达化验基线实际计算；延迟改变信息可用性 |

## 记录格式

逐例记录审查文件与散列、执行命令、实算结果、发现的路径/行与修复建议。状态分为：通过、待修复、未检查。修复后重查相关路径并保留发现历史。

本轮不执行付费模型调用，不查看用户浏览器或凭证，不将教学样本上的成绩包装成现场表现。页面只保留与读者判断有关的数据说明；本审查不会要求页面堆叠自证式免责声明。
