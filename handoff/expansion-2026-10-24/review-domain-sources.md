# 专业概念复核来源

2026-10-24 实际检索并阅读以下官方材料，供 12 例作者核对图解与措辞。只用于专业概念复核，未下载外部图片或代码，也不等于对教学生成器作现场标定。

| 案例 | 复核要点 | 一手来源 |
| --- | --- | --- |
| g1 | 不同地表材料在各波段反射不同；多波段解译依据是地表光谱差异 | [USGS 光谱实验室](https://www.usgs.gov/labs/spectroscopy-lab)、[NASA 用光谱绘制矿物图](https://science.nasa.gov/earth/earth-observatory/mapping-minerals-with-light-83324/) |
| s1 | 地震事件是反射等能量到达所形成的波形或连续同相轴，可能对应地质界面 | [SLB seismic event](https://glossary.slb.com/en/terms/e/event) |
| d1 | ROP 是钻头破岩时井眼推进速度，常见单位 m/h；钻压、转速变化需与岩石条件区分 | [SLB ROP](https://glossary.slb.com/en/terms/r/rate_of_penetration) |
| c1 | CBL 读取套管声波振幅/衰减；VDL 把完整接收波形随深度呈现为灰度/颜色；单振幅还受微环空影响 | [SLB CBL](https://glossary.slb.com/en/terms/c/cement_bond_log)、[SLB VDL](https://glossary.slb.com/en/terms/v/variable-density_log) |
| co1 | 裸眼完井缺少储层段套管支撑，选择性干预有局限；防砂是阻止储层砂进入井筒的配置 | [SLB 裸眼完井](https://glossary.slb.com/en/terms/o/openhole_completion)、[SLB 防砂](https://glossary.slb.com/terms/s/sand_control) |
| p1 | 射孔入口与通道几何影响流动；防砂完井可重视较大孔眼，几何意义应配合场景解释 | [SLB Choosing a Perforation Strategy](https://www.slb.com/-/media/files/oilfield-review/p54-69) |
| pr1 | 理想井下泵功图近矩形；地面图受到杆柱等影响，二者不能直接混称 | [SLB Defining Rod Pumps](https://www.slb.com/resource-library/oilfield-review/defining-series/defining-rod-pumps) |
| e1 | 压裂连通井筒与储层，支撑剂用于维持裂缝张开；导流能力由裂缝渗透率与宽度共同决定 | [SLB Defining Hydraulic Fracturing](https://www.slb.com/resource-library/oilfield-review/defining-series/defining-hydraulic-fracturing)、[SLB fracture conductivity](https://glossary.slb.com/terms/f/fracture_conductivity) |
| t1 | 泄漏检测可联合流量、压力及泵阀工况；正常作业瞬变也会改变观测，单一阈值存在混淆 | [PHMSA Leak Detection Systems](https://primis.phmsa.dot.gov/stakeholder-comms/factsheets/fsleakdetectionsystems/) |

wo1 的检索与约束、w4 的多曲线岩性判断、r5 的化验时刻与软测量，本轮重点核对的是作者实际数据和算法调用路径；没有在此表追加未经逐页核对的领域结论。
