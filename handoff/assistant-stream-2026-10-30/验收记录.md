# 井见助手 0.7.0 · 2026-10-30

本轮交付放大后的 Live2D 轻量对话、流式输出、服务器代理与本机历史。界面和本机真实模型链路通过；云端代理已公开发布，但当前网络访问托管域名被 Cloudflare 返回 403，**GitHub 访客直接调用云端模型尚未通过验收**。

## 界面与交互

- 桌面 1440×900、1366×768：整体 440×384px，人物画布约 190×200px，输入面板 360px 宽。
- 窄屏 390×844：整体 366×334px，输入面板 340px 宽，人物约 140×146px。输入文字 18px，自动增高 54–108px。
- Live2D 沿用原嘉然资源。打开对话、历史、语音偏好时保持同一个画布。
- 移除访客填写 Model ID、API Key 和接口地址的表单；底栏改为单行状态、历史、新建、语音偏好和收起。
- 实测流式增量显示、停止后保留部分回复、迟到回复隔离、新建、删除、完整历史滚动与刷新恢复。完整历史保留 30 条时，模型请求只携带最近 24 条。

## 模型实际调用

使用与托管版本相同的 Worker 源码，在仅监听本机的临时代理中调用火山方舟。Key 通过隐藏输入进入进程内存，未写入测试文件、浏览器或仓库。测试结束关闭该临时代理。

| 输入 | 实际结果 | 首次增量 | 增量数 |
| --- | --- | --- | --- |
| 文字 | 模型解释钻井液携气过程 | 1095ms | 82 |
| 图片 | 识别井架及干旱荒漠地表 | 2646ms | 86 |
| 音频文件 | 复述中文录音问题并作答 | 900ms | 63 |

首次增量时三次请求仍在生成，页面已经出现文字。响应采用真实 SSE 增量；不是将完整结果拆字播放。测试内容、用量及请求头名称见 `browser-online.json`。请求不携带模型 Authorization 或 Key；附件历史只保存名称。

录音入口另通过 Chrome 模拟麦克风验证 `getUserMedia → MediaRecorder → WAV → 模型`，最终录音 7.38 秒，模型复述了“气体从井底到地面为什么需要时间”。系统朗读入口与停止动作完成，浏览器报告 speaking 与人物嘴型均启动；**未验证实体麦克风及扬声器实际听感**。

第一次录音模型仅返回导航，随后对“复述／逐字／转写”请求关闭导航工具。两次后续检查还发现录音过短及测试再次点击已打开面板的问题，已延长录音并改为每次重新打开页面。失败及中间记录保留在 `browser-audio-attempt*.json`，最终记录为 `browser-audio.json`。

## 云端配置与未完成项

使用 Sites 托管 Worker；公开地址为 https://jingjian-assistant-relay.richcreek513.chatgpt.site 。模型固定为 `doubao-seed-2-0-mini-260428`，Key 保存在服务端 Secret `ARK_API_KEY`。前端配置只包含公开接口 URL。用户已选择所有访客直接使用、消耗其模型额度。

平台返回部署成功、公开访问策略和环境版本 1；构建源码提交与版本信息见 `deployment.json`。当前本机用 localhost 和 GitHub 两个 Origin 请求状态接口均收到 Cloudflare 403，因此无法把平台部署成功写成访客端调用成功。当前页面保留本地导览，并在语音偏好内提供连接状态和重试。

代理限制请求大小、固定上游和模型、过滤消息与导航参数、限制输出长度，并做单实例短时频率控制。该频率控制不等于全局持久预算封顶。访客公开使用前仍需解决托管域名的公网可达性并复测。

## 复现与材料

- 源码检查：`node checks/verify-assistant-stream.mjs`。
- 同步检查：`node checks/verify-assistant-sync.mjs`。
- 浏览器检查入口：`node checks/browser-assistant-stream.mjs ui|online|audio|paths`；online/audio 需要安全的本机代理和对应测试浏览器设置。
- 同步入口：`node tools/sync-assistant.mjs --avatar-loader-ref=554d236`。本次固定已验证的头像加载器，独立于工作区中的性能修改。
- 打包入口：`node tools/package-assistant.mjs`。
- 后端源码：同级目录 `../jingjian-assistant-proxy/worker/index.js`；构建产物与源提交由 Sites 工作流归档，秘密不在源码包中。
- 成品包：`dist/s17-all-61-assistant-0.7.0.zip`、`dist/s17-site-assistant-0.7.0.zip`。ZIP 的 CRC、成员数及每个成员 SHA256 均实际核对，见 `package-lock.json`。

本轮使用 Sites 技能完成秘密配置、发布和访问范围设置，使用 Playwright 技能完成 Chrome 验证。案例仍可纯前端离线计算；联网助手通过独立代理调用模型。
