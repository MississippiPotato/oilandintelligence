## 添加和更新

在老师原站或增强门户点击“＋ 添加案例”，一次选择 `dist/cases/` 下的**一个完整案例文件夹**，待标题和ID填入后“校验并添加”。每例仍只有 `case.json`、`README.txt`、`demo/index.html`、`demo/demo.css`、`demo/demo.js` 五个文件。先解压ZIP，不选cases总目录，不选源码目录。

已有1.1或1.2旧包的浏览器不会自动覆盖原记录。首页会标记旧版，并把主入口指向新版独立成品。要在门户中更新，请在案例库移除**自己的旧包**，再用原入口导入1.3目录。注册状态属于当前浏览器和地址；换浏览器或清除存储需重新添加。

本轮实际通过原站连续导入五例、运行、下载JSON、刷新后重算；断网file模式也完成五例导入与刷新。增强门户接受原样firstbreak样例，滑块和刷新正常。原站深层控件的自动化点击曾落到父站标签，下载等待超时；最终采用键盘焦点完成离线HTML下载，失败记录没有删除。

## 开发与复核

Node.js，无生产依赖，无需npm install：

```powershell
npm run build
npm test
npm run verify-delivery
npm run verify-guide
npm run package
npm run serve
```

build重新构建五例及真实算法生成的上游快照；test运行37项既有计算/分组/来源/分母检查，**这些不是浏览器通过**。verify-delivery/verify-guide核对当前成品、实际持久包、默认指标与浏览器记录。package生成本次1.5预览包和五个1.3独立ZIP，保留旧版ZIP。serve只绑定127.0.0.1:8755。

启动后打开 http://127.0.0.1:8755/ ，根目录会进入增强门户；老师原站位于 http://127.0.0.1:8755/portal-original/index.html 。直接双击根目录index.html也可离线进入。Git仓库包含当前交付文件及上一版回归核对所需的包，不包含浏览器配置、解压副本、替换掉的角色和saphirv3参考项目。

当前浏览器专项记录：教学交互75项、首页15项、原站HTTP/firstbreak44项、file离线62项，另有角色收起和旧包升级提示记录。专项内容可能交叠，不累加为独立验收总数，也不换算教师评分。最终图文说明包含本轮限制、截图与失败尝试。
