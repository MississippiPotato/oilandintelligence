# m2 外行可读性审阅与修改（1.7.1）

用户提出两项调整：删除“进阶与计算依据”整块；请独立子Agent判断专业背景和流程能否被没有石油背景的本科生读懂。

审阅由 `/root/m2_beginner_review` 完成，两轮均为只读，阅读知识稿、实际页面内容模块、六步流程与绘图代码；未操作浏览器，也不代表真实学生参与的可用性测试。

初审判断：采集链、双时钟、组分和工况的主线已成立，外行能够理解不能看到气峰便直接判断产气层；但几个术语、因果连接和检测图文仍会阻碍独立复述。

| 发现 | 本轮修改 |
| --- | --- |
| 首次使用“气峰”没有直接定义 | 第一节说明读数相对平时升高并回落，横轴为时间、纵轴为仪器读数，并指定峰A |
| 排量与有效运移体积直接进入公式 | 先解释每秒泵送液体量、运输所需推进的等效体积，再给12m³÷0.025m³/s例子 |
| 用“抽汲”解释增气但未解释抽汲 | 补钻柱与钻具移动引起局部压力降低的活塞类比，保持“可能”的专业条件 |
| 先见相似性结果表，再见kNN定义 | 把事件库、比较气峰与工况、相似事件投票放在表前，解释距离与支持度 |
| 来源与工况由程序结论直接告知 | 在双时钟图下加实际作业时间带，与来源蓝线共轴；说明来源时刻落在区间内时时间间隔为0秒 |
| 检测步骤讲平滑与阈值，但图没有对应 | 绘制实际相邻3次平均、背景线、背景加阈值线，与实际候选窗口对应 |

复审确认上述六处得到实质修正，另发现并修复两处细节：固定规则描述需说明“考虑来源工况”的开关条件；检测图中的朱红峰顶点应使用平滑值，与图例保持一致。

页面结构同时精简：`#advanced`整体删除，没有把训练参数、指标、人工复核表单藏回其他主线区域；必要计算沿用固定默认设置，仍执行真实模型、规则和评价，`M2Inspect`及证据交换格式保持。演示底部仅保留小型“保存本次结果”入口。公开顶空气62条原始读数移入专业背景的资料来源，未用于气峰分类。

特征步骤先显示峰宽、组分变化比和作业时间间隔三个可理解的量，完整标准化表按需展开；最终流程给出证据清单与下一步核查。修改只针对m2，其余60例和老师原站受保护文件通过哈希核对。

实际浏览器验证与源码／数值检查分别记录在本目录的 `browser.json` 和 `source-and-calculation.json`；不要把本篇审阅当作浏览器通过记录。
