# 井见助手 0.7.1 · 手动 Key

按用户最新决定，暂停云端共享代理，改为每位使用者在网页填写自己的火山方舟 API Key。已移除托管代理中的 ARK_API_KEY，并以环境版本 2 重新部署生效；前端不再连接该代理。

打开助手，点击底栏红色“连接”即可填写。只有 Key 输入和连接按钮，默认模型为 Doubao Seed 2.0 mini，不再展示 Model ID 或接口地址等大表单。Key 仅在当前页面内存中使用，输入后清空密码框，不写入对话历史、localStorage、sessionStorage 或 IndexedDB；刷新或跳转整页后需重新填写。历史对话照常保留。

放大后的 Live2D、回复气泡、流式增量、本机历史、附件和录音入口保留。本轮没有新增云服务或创建 Vercel 账号。

实际 Chrome 验证通过：打开入口、空值提示、连接后清空输入、正确携带测试 Key 与 stream:true、SSE 接收、断开清空、刷新失效、历史和 Web Storage 无测试 Key、390px 窄屏面板与底栏布局。流式适配器测试使用无效测试字符串及受控 SSE，**不是真实有效 Key 的模型调用**。

实际用无效 Key 直连方舟时，浏览器没有读到鉴权回复，控制台显示 CORS 拦截；独立 OPTIONS 检查返回 200 且允许 Origin 和 Authorization。不能据此宣称有效 Key 已能在浏览器直连。**当前手动输入模式的有效 Key 直连未验收**，首轮实际提问成功后界面才显示“在线”。此前文字、图片和音频的真实模型调用通过的是临时本机代理，记录保留在 `../assistant-stream-2026-10-30/`，不可移作本次直连通过的证据。

本轮助手同步限定原 61 例、305 个运行文件；新出现的其他变体不计入本次发布范围。核对计算代码、助手外样式及其余 183 个案例文件在本轮同步中保持不变，老师原站 46 个文件保持 Git 基线。完整记录见 browser.json、sync-checks.json、cloud-disabled.json 和 release-index-checks.json。未重复全 61 例算法或浏览器验收。
