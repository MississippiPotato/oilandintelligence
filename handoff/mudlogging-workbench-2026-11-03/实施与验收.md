五例均保留专业背景、照片、画卷、原计算引擎和训练资料。首页、井见助手、老师原站及其余60例未在本轮改版。其他60例的300个运行文件与基线一致；保护文件443项一致。M5仅公开三个既有纯展示／来源帮助函数，函数主体未改。

## 本轮完成

- 连续流程讲义：M1—M4各六步，M5五步。每步给出问题、处理动作、对应图与具体产物；标明数据准备／处理、AI核心和结果核对。关键数据由原引擎实际计算，讲义与实验台输入独立。
- 固定实验台：预览→加载→手动运行→交互结果。三个阶段在同一位置替换主体，首次不显示本次预测。成功运行后修改适用条件自动重算；换数据回到待处理，过期结果禁止保存；保留复位、重新运行和保存。
- 文件真实进入计算：页面生成配套样本供下载；M1/M3为320×240图像JSON，M2为气测与工况JSON，M4为CSV，M5为UTF-8 TXT。导入校验不覆盖上次有效输入，不接收评价真值、不沿用内置准确率。
- 保留五文件导入契约和snapshot()/evidence()。快照补充阶段、数据来源、指纹和处理状态。M2两种比较路径读取同一载入观测；工况反事实保持气测逐点不变。
- 只给五例的独立页面、样式脚本和门户文档入口增加1.11.0缓存标识；没有重建其他60例。

## 老师原站与离线边界

五例分别通过原站“添加案例→选择文件夹→校验并添加”，刷新后重新加载示例并运行。原站正常给出包体／清单偏大的建议警告，未超过6MiB硬限制。最终带缓存参数的五文件在原站解析、刷新及运行又抽查M3。

发现的原站限制：在8755同一存储环境里，M1、M2可一起留存，继续加入M3后，M3刷新丢失。原站采用localStorage，未修改其实现；M3、M4、M5在独立干净的本地源分别验证了单例持久化。没有声称原站能同时保存本轮全部大包。

五例已载入的独立页面，在浏览器网络设为离线后均能从预览加载并计算；测试后恢复网络。冷启动file://受到浏览器自动化工具的协议限制，本轮未验收，未通过其他工具绕过，也不以脚本无外链或源码检查替代。

原站沙箱点击保存，实际捕获到子框架Page.downloadWillBegin；工具未返回该下载的完成文件。因此原站沙箱“下载完成”仍未确认。五个独立页面已各实际下载结果并读回JSON；该结果与原站下载边界分别记录。

## 交付与复现

- npm run build：只构建本轮五例及必要门户登记。
- npm test：范围核对与必要数值检查。
- npm run package：在浏览器记录完成后生成五个单例ZIP、五例合集及当前完整离线网站，校验ZIP CRC及每个成员SHA-256。
- 单例ZIP解压后，在老师原站选择完整案例目录。增强门户支持现有ZIP导入。
- 小型案例包与合集随Git提交；完整离线站点包在本地dist生成，避免重复的大站点二进制进入本轮Git历史。

发布与线上实际观察另见publication.json。若文件尚不存在，表示该步骤仍在执行；不以git push成功代替线上版本验证。
