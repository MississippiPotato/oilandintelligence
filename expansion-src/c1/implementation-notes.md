# c1 固井质量智能评价

原场景 `c1`，案例 ID `s17x-c1-cement-quality`，版本 `1.0.0`。方法字段采用 `ts`：四个输入来自声学波形时间窗的 RMS、能量比与差分 RMS；VDL 用于按深度展示完整声波，不把显示图本身称为图像识别算法。

内容维护入口为本目录 `generate-source.py`（两例的专业图解、HTML、CSS、manifest）和各自 `ui-body.inc`（交互逻辑）；执行生成脚本得到完整 `app.js`。`engine.js` 单独维护。总构建器只取约定六件源码，不取生成脚本或报告。

背景三图分别解释套管—水泥环—地层的耦合、CBL 与 VDL 的信息差异、微环空导致单声幅歧义。流程五步均有输入、动作、产物、独立 SVG 图解和一个需要留意的问题。演示联动深度曲线、真实波列矩阵、分类带、当前波形与真实训练近邻。

默认教学数据按 18 / 6 / 4 口独立井划分，每井 48 个深度点，生成 80 点声波。18 口训练井拟合标准化并存储特征库；6 口验证井选择 k 和声幅基线双阈值；4 口测试井共 192 点，标签仅由评价函数读取。模型通过距离倒数投票，不读取井名、深度或生成类别。

默认真实计算结果：k=9；模型宏 F1 `0.9498812648418947`，声幅基线 `0.6746594064700964`；模型接受 187 / 192 点，其中错 7 点，拒判 5 点。高噪声 0.22 时模型 F1 `0.3462157809983897`，低于基线 `0.47155563013928514`，保留这个失败预设以展示方法条件。

人工意见携带 runId、inputRevision、当时观察快照和原预测；输入变化后标为历史，新计算不继承当前确认。下载 JSON 包含 07 协议的最小 envelope、实际波形 source/selector、推断 claim、人工历史；参考链接独立放 references。
