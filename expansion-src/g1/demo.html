GEOLOGY / G1 / 地质勘察

从多波段像素，读懂地表单元

一幅影像，三种岩石外观，一片植被。让每个候选解释都能回到观测与训练证据。

先理解：地质信息怎样成为影像？

把露头、反射波段和分类地图连成一条证据链。

B01 / CONCEPT

从地质露头，到一个遥感像素

地质勘察需要识别地表岩性单元及其接触关系。卫星把地表反射光记录为栅格，帮助安排填图和露头核查路线。

B02 / CONCEPT

换一个波段，看到另一种差异

红光、近红外和短波红外记录不同波长的响应。组合波段能增加识别线索；阴影、风化与植被也会改变观测。

B03 / CONCEPT

把颜色，变成带证据的候选判断

模型学习的是当前标注体系下的表面外观。三类露头与植被覆盖使用不同标签；点选像素能查看来自训练图幅的真实邻居。

专业依据：USGS：遥感与波段；墨西哥地质调查局：地质遥感填图。图形为本案例自绘；光谱数值与图幅均为教学合成。

五步，把影像变成可复核的解释

每一步都能在演示中找到对应输入或中间产物。

STEP 01 / 数据

按图幅划分，先看数据

输入·动作
输入：3个反射率波段与整幅地表类别标注。动作：以图幅ID分组，6幅训练、2幅验证、1幅独立测试。图 S1 显示划分。
产物
产物：576个训练像素、独立验证像素和完整72×48测试图；同图相邻像素不跨集合。
关键点
同一图幅的裁块混到训练和测试，会把空间相似性误算成泛化能力。
STEP 02 / 特征

从观测波段提取6维特征

输入·动作
输入：实际波段数组。动作：逐像素计算3个通道、2个归一化差异和3×3红光标准差，图 S2 对应可见特征。
产物
产物：每个像素的6维向量；仅训练样本拟合均值与标准差。
关键点
合成器的类别标签只用于训练标注与后续评价，不进入测试特征。
STEP 03 / 学习

建立有来源的近邻库

输入·动作
输入：训练特征和训练类别。动作：训练组标准化后，按欧氏距离寻找近邻并做距离加权投票，见图 S3。
产物
产物：可点开查看的实际训练邻居、距离和近邻支持度。
关键点
近邻投票的支持度是相对票重，不能当作已经校准的概率。
STEP 04 / 验证

用验证图选择k与阈值

输入·动作
输入：两幅独立验证图。动作：实算 k=3、5、7 的宏F1；红光基线也在同一验证图上选择阈值偏移，见图 S4。
产物
产物：锁定的k、单波段阈值和验证记录；测试滑杆改动属于探索。
关键点
测试结果不能反向参与参数选择；特征消融会重新使用同一训练和验证划分。
STEP 05 / 解释

比较地图、定位错误并复核

输入·动作
输入：同一幅测试图的观测。动作：分别运行基线与kNN，计算含拒判列的混淆矩阵；点选像素后填写人工意见，见图 S5。
产物
产物：分类图、宏F1、各类IoU、人工意见和可下载JSON；原模型指标保持独立。
关键点
先修改输入再重算；导出只对应当前已经完成的一次运行。

每一类分得怎么样？

运行后显示各类TP、FP、FN、IoU与F1。

IoU = TP / (TP + FP + FN)，F1 = 2TP / (2TP + FP + FN)。整幅3456像素参与评价，待复核仍计入对应类别FN；缺席且无误报的类别显示“不适用”。人工意见不覆盖模型原始结果。
