# co1 完井方式智能优选

原场景 `co1`，案例 ID `s17x-co1-completion-choice`，版本 `1.0.0`，方法字段 `kg / opt`。在任务卡公开规则推理的基础上，加入真实的四输出 kNN 回归来估计方案响应，再执行显式约束与效用排序；规则约束与学习模型分别展示。

专业内容、HTML、CSS 与 manifest 维护于 `../c1/generate-source.py`；本例交互逻辑维护于 `ui-body.inc`，生成得到完整 `app.js`；算法独立维护于 `engine.js`。

背景三图解释四种完井构型、出砂与分层控水的不同需求、学习响应与可行域的分工。套管方案的教学配置含选择性封隔；裸眼筛管不含分层封隔器。温度额定、费用和响应分数均为本例可见教学设定。

库为合成历史试验井：160 口训练井、40 口验证井、32 口测试井，每口井有四个配对方案响应，同一井四方案不跨集合。六项预测输入是强度、出砂、非均质、控水、log10 渗透率和温度。训练集拟合标准化，验证 MAE 从 k=3/5/9/15 选 k；预算、井壁支撑、防砂、分层控水、设备温度条件显式筛除候选。

默认真实结果：k=15，留出 32 井 × 4 方案的 128 个响应 MAE `2.8058105435190632`。模型推荐 32 / 32 井，31 / 32 与参考可行最优一致；平均机会损失 `0.0294595160361395`。经验规则经相同约束检查后推荐 21 / 32 井，其中 18 / 21 选对，平均机会损失 `0.15760121616378747`。机会损失同时列出各自有推荐分母，不能忽略覆盖差异。

双重出砂/控水需求预设能定位经验筛管首选的隔离冲突。预算不足预设在当前自定义井保留空可行集；32 口固定留出井的全局评价仍单独报告。自定义井不显示准确率或参考最优。缺失/非有限数值输入会明确报错，不把比较失败默认为条件满足。

人工历史、待重算、恢复默认和 JSON 下载均有实际动作。证据 sources 携带当前六项条件、预算、偏好和候选配置，sourceVersion 随内容变化；claims 带 selector。参考链接与实际观测来源分开。

`node expansion-src/co1/verify.mjs`：10 项计算/源码检查全部通过，记录在 `verification.json`。实际独立页面检查见 `../c1/browser-report.json`（两例共 42 项通过、0 失败）。下载内容另经 `../c1/verify-downloads.mjs` 做 10 项检查全部通过。`browser-evidence.json` 是浏览器实际点击下载的文件；桌面/窄屏截图在本目录。

最终 BUILD_READY_3 的尺寸与新助手包又做 15 项针对性检查，见 `../c1/browser-display-report.json`：正文桌面 18px，SVG/Canvas 原尺寸局部滚动，390px 助手真实开合、计算状态保持，file 离线运行指标一致；最新截图已人工查看。
